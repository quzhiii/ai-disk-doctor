# AI Disk Doctor v1.7.0

v1.7.0 focuses on making AI Disk Doctor easier to start and safer to distribute. The headline feature is a one-click deploy path for first-time users: `Start-AIDiskDoctor.ps1` runs a read-only scan, writes a Markdown report, generates a local HTML dashboard, and opens it without requiring users to learn the full CLI workflow first.

## What Changed

- Added `Start-AIDiskDoctor.ps1` as a one-click, read-only onboarding entrypoint.
- Added default quickstart outputs under `.aidisk\quickstart\`:
  - `scan.md`
  - `aidisk-dashboard.html`
- Added optional deeper report flags:
  - `-IncludeDoctor` writes `doctor-ai-footprint.md`
  - `-IncludePlan` writes `safe-cleanup-plan.md`
- Changed PowerShell Skill wrappers to prefer installed or local binaries before falling back to Cargo:
  - `AIDISK_EXE`
  - `aidisk` on PATH
  - local release/debug binaries
  - debug Cargo build fallback for source checkouts
- Added shared wrapper helper `skills/windows-ai-space-manager/scripts/invoke-aidisk.ps1`.
- Updated release packaging so extracted artifacts include:
  - `Start-AIDiskDoctor.ps1`
  - built-in `rules/`
  - default `config/`
- Changed local scan snapshots and rules-repo caches to resolve from the current working directory instead of the compile-time source tree.
- Promoted the crate, README, package-manager drafts, and trusted distribution docs to v1.7.0.

## One-Click Deploy

Default quickstart:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Start-AIDiskDoctor.ps1
```

Optional deeper diagnosis:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Start-AIDiskDoctor.ps1 -IncludeDoctor -IncludePlan
```

The default path is intentionally read-only and dashboard-first. Real cleanup still requires an explicit `aidisk clean --yes --quarantine-root <path>` command.

## Safety Boundaries

- One-click deploy does not execute `clean` and does not delete or quarantine files.
- Optional `-IncludePlan` only writes a safe-only preview; it does not run cleanup.
- Optional `-IncludeDoctor` remains read-only and does not invoke external tooling unless future CLI flags explicitly request probes.
- Release packages include rules and config so binaries do not depend on the developer's original source checkout.

## Known Limits

- One-click deploy currently uses PowerShell, so non-Windows users need PowerShell installed or should use the native `aidisk` CLI directly.
- The dashboard is based on the newest scan snapshot generated during the one-click run.
- First source-checkout execution may build the debug binary if no installed or local `aidisk` binary is available.
